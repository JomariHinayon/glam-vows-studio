# Design fonts

Drop the licensed font files here (`.woff2` preferred, `.otf` also works).
They load automatically; no code changes needed.

| File name                          | Font                                       |
|------------------------------------|--------------------------------------------|
| `EditorsNote-Extralight`           | Editor's Note Extralight (headings)        |
| `EditorsNote-ExtralightItalic`     | Editor's Note Extralight Italic            |
| `EditorsNote-Light`                | Editor's Note Light (logo)                 |
| `EditorsNote-LightItalic`          | Editor's Note Light Italic (chapter titles)|
| `NeueHaasDisplay-Roman`            | Neue Haas Grotesk Display Pro 55 Roman     |

Until these are added, size-matched open fallbacks are used (see `src/styles/fonts.css`).
